# 本地语音提示词：简短沟通与自主配置

本次按用户反馈调整提示词和设置页文字，模型协议、切换逻辑和资源估算数值保持原样。

- 第一阶段只检查电脑与目标模型是否匹配，默认用 3–5 句短话给出适合程度、日常使用影响和大致下载/空间需求；不安装、不要求正式方案摘要。
- 用户发出第二阶段提示词即授权该次常规下载、独立环境、适配、测试、排错和登记。指定模型按目标实施，通用提示词没有指定时由 agent 保守选择一个；无需逐步确认。
- 使用者不需要选择运行时、精度、目录或启动技术方案。agent 自行检测、复用，并采用保守默认值；重要目标冲突、系统变动、影响其他应用、付费或明显超过约定资源时才询问。
- 开始和进度回复保持简短，完成最多 5 句。技术细节写入本地说明，用户追问时再展开。协议和真实语音验收仍须执行，不能用静音或模拟结果夸大能力。
- 卡片按钮改为“① 看电脑适不适合”“② 帮我装好”。界面明确按钮复制提示词、把第二份发给 AI 才会开始安装，去掉运行时和量化等说明。

证据在 `artifacts/prompt-plain-language-20261104`：两套皮肤的复制/显示流程、50 项原生回归、发布构建及成品对应核对。测试证明复制内容、阶段边界文本和发布包一致；不能保证第三方 agent 一定遵守沟通方式。

安装和原设置保留的结果以该目录中的 `installed.json` 为准；此前版本备份在该文件的 `backupRoot`。
