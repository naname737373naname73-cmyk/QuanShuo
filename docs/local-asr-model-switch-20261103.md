# 本地模型登记与界面切换验收

本次在现有三张模型推荐卡上增加定向的两阶段提示词、接入状态、只读刷新和验证切换。主程序仍不包含模型或推理环境。

## 使用方式

1. 在所选模型卡复制“① 检测此模型”，让 agent 只读检测并讨论资源预算。
2. 选定方案后复制“② 安装 / 接入”，交给同一 agent；已有环境和权重应复用。
3. agent 实测并登记后，点“刷新已接入模型”，再“验证并切换”。

登记仅包含连接资料，固定三项 ID；文件不存在显示“尚未接入”，文件存在但未验证显示“已登记 · 切换时验证”。这不是扫描模型权重，也不把下载完成等同于服务可用。

## 程序保证与服务职责

- 原生层读取登记后，按半秒静音协议验证实际 `name` 与 `catalogId`，两者一致后才保存本地连接。失败保留原配置，不能自动改到云端或下载模型。
- 录音、重转写、连接测试与切换互斥。切换中拒绝录音时，窗口仍能结束和关闭，手动文字保留为未完成记录。
- 保存操作共用跨窗口互斥锁，并用设置版本号拒绝过期界面覆盖。切换只更新本地连接，保留其他配置；同一设置表单里未保存的其他编辑仍在。
- 同一网关失败后请求原配置至多 30 秒，提示仍需重新确认身份，不声称原模型已经恢复。失败后历史身份缓存失效。
- 服务负责模型装载、空闲释放、设备预算和启动方式。多 GPU 模型须先释放旧占用再加载新模型；不同端口也须协调，不能只依赖空闲超时。程序不执行登记中的脚本。
- 两阶段提示词是交给第三方 agent 的约束，应用不能机器阻止 agent 越权；第一阶段明确禁止下载、安装、启动和加载。
