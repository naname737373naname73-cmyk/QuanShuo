# 圈说使用说明

**适用版本：0.1.1 预览版 · Windows 10 / 11 x64 · 更新于 2026-11-05**

圈说把屏幕上的一块内容、你说的话和来源信息放进同一条记录。你可以把它复制给 AI，也可以只把语音变成文字。记录保存在自己的电脑上。

## 一、它能解决什么问题？

| 你遇到的烦恼 | 用圈说怎么做 |
| --- | --- |
| 想让 AI 看一个按钮、报错或图表，却要反复解释“哪一块” | 圈住目标，开口补充“这里太挤了，帮我改一下”，把截图路径、说明和来源一起复制 |
| 想法很多，打字跟不上，或者需要输入一段较长的文字 | 打开语音输入，说完检查一下，再把文字贴到当前要用的软件里 |
| 截图散在文件夹，说过的话混在聊天里，过后找不到 | 在本机历史里按文字搜索、按日期找，继续编辑或批量复制 |
| 语音服务断开，担心刚才说的一段白说了 | 识别失败时保留已有文字和录音，修好配置后可以重新转写 |

比如，你可以圈住设计稿的一处间距，说“把这两个按钮对齐”；圈住代码报错，说“帮我解释原因”；也可以在写长消息时直接口述。

**圈说负责收集、转写和整理输入。** 它本身不替你回答问题，也不改写原话。分析截图、修改代码等工作仍交给你使用的 AI 工具。

## 二、安装后，从哪里打开？

1. 打开上面的 GitHub 发布页，找到 **Assets**。
2. 通常下载 **QuanShuo-Setup.exe**，双击安装。默认装到当前用户目录，不需要管理员权限。
3. 希望免安装时，下载 **QuanShuo-portable.zip**，解压后运行 **QuanShuo.exe**。
4. 安装版和便携版选一个即可。GitHub 的 **Source code** 是开发源码，不是安装包。

主程序已经包含 .NET 运行时，不用另装 .NET。历史记录和设置界面需要 WebView2；系统缺少时，程序会给出微软官方安装入口。

圈说会常驻右下角托盘，图标可能收在“小箭头”里。**双击圈说图标打开历史**，右键可以打开设置、截图、说话或退出。再次运行程序也会唤起历史窗口。

第一次启动可以先跳过 API Key，试试截图和手写说明。要自动把语音变成文字，再按第四或第五节配置识别来源。

更新时，先在托盘右键选择 **退出**，再运行新安装包。卸载会保留记录和设置；程序不会替你搬迁旧记录。

## 三、日常使用，只记住两个入口

### 方式 A：圈一块屏幕，补一句说明

1. 在想说明的内容前按 **Ctrl + Alt + G**。
2. 按住鼠标左键拖动圈选，松手完成。圈选时按 **Tab** 可切换矩形与自由圈选，按 **Esc** 取消。
3. 按 **Space（空格）** 开始说话；如果只需要截图，按 **Enter** 保存。
4. 看一眼文字，有错可以直接改。按 **Enter** 结束录音，完成后点 **复制给 AI**。
5. 到你使用的 AI 工具里粘贴。

**截图不会因为“复制给 AI”就自动上传到网页。** 复制内容含图片的本机路径、说明和来源。能读取本机文件的桌面 AI Agent 可以使用该路径；网页版聊天工具通常需要你再上传图片。若 AI 说看不到图，先检查这一步。

### 方式 B：只说话，输入一段文字

1. 先点一下准备输入文字的位置，再按 **Ctrl + Alt + H**。
2. 开口说话，识别结果会逐步出现；当前句在确认前可能修正。也可以点进文字框手动编辑。
3. 查看发送按钮显示的目标，按 **Enter** 结束并把文字贴过去。目标不可用时可以复制，再自行粘贴。

语音输入窗口里的 **Esc** 会结束录音，文字仍留在窗口。贴回其他软件通过剪贴板完成，会替换原来的剪贴板内容；重要文字发送前请检查一遍。

### 暂停、继续和自动暂停

- 点击 **暂停 / 继续**，或在没有编辑文字时按 **空格**，可以暂停或继续录音。
- 点击文字或按 **Tab** 进入编辑后，空格就是普通空格，不会误触暂停。想继续说话，可以点 **继续**。
- 连续 **1 分钟没有检测到说话**，自动暂停并显示 **静音已暂停**，已有文字和录音保留。手动继续后重新计时。
- 自动暂停在本机判断有没有语音，不是根据“有没有及时出字”。它不需要另下模型；暂停也不等于退出或卸载本地识别模型，不会因此释放模型显存。

| 操作场景 | 按键 | 作用 |
| --- | --- | --- |
| 全局 | Ctrl + Alt + G | 圈选截图 |
| 全局 | Ctrl + Alt + H | 只说话 |
| 圈选中 | Tab / Esc | 切换圈选形状 / 取消 |
| 录音中，焦点不在文字框 | Space | 暂停 / 继续 |
| 编辑文字时 | Space / Shift + Enter | 输入空格 / 换行 |
| 录音窗口 | Enter | 结束；语音输入窗口会尝试贴回目标 |

两个全局快捷键可以在设置中修改。和其他软件冲突时，换一组即可。

## 四、想用本地语音识别，让 AI 帮你装

本地识别把音频交给本机服务。**模型和运行环境需要单独安装**，圈说安装包不包含它们。首次下载需要联网；模型及环境准备好后，本机服务正常运行时可以在本机识别。

你需要一个能操作本机、安装软件和修改配置的 AI Agent。普通网页聊天窗口如果不能操作电脑，就无法自动完成这些步骤。

打开 **设置 → 语音识别 → 本地服务**，按顺序操作：

1. **先检测。** 在模型卡上点 **① 看电脑适不适合**，或者复制通用检测提示词，粘贴给 AI Agent。它会检查电脑和可用资源，先用简单的话告诉你建议；这一步不安装。
2. **再安装。** 决定采用建议后，点对应模型卡的 **② 帮我装好**，把安装提示词发给 Agent。它会完成常规环境、模型、服务和应用连接的配置。让它保留你正在使用的其他软件环境。
3. **回到圈说。** 点 **刷新已接入模型**，在对应模型卡点 **验证并切换**。成功后会保存配置；失败时保留原来的选择。
4. **实际试说。** 用十几秒日常中文夹英文试一下，看文字是否及时出现、有无漏字。服务检查通过不等于所有实际语音都识别得好。

### 三个推荐选项，怎么选？

以下是应用展示的**初步资源预算，不是硬件最低要求或实测保证**。推理方式、精度、驱动以及其他软件的占用都会影响结果。

| 模型 | 应用中的初步预算 | 适合先怎么尝试 |
| --- | --- | --- |
| Paraformer Streaming · INT8 | 模型显存 0 GB；系统内存先留约 1–2 GB | 希望省显存，或显卡正被其他软件占用时，优先让 Agent 检查这个 CPU 方案 |
| Qwen3-ASR · 0.6B | 模型显存先留约 4–6 GB | 有可分配显存时，让 Agent 检查后再安装 |
| Qwen3-ASR · 1.7B | 模型显存先留约 6–8 GB | 资源较充足时，与较小模型对照试说，再决定是否使用 |

**看的是当前能留给模型的余量，不是显卡包装上的总容量。** 16 GB 显卡开着游戏、绘图或其他模型时，也未必有足够余量；6 GB 或 8 GB 显卡同样可以考虑不占独显显存的 CPU 方案。不用自己死记硬件术语，让检测提示词帮助你判断。

表中数字也不代表完整安装成本。Python、推理框架、下载缓存，以及某些方案需要的 WSL / 容器，都可能另外占用磁盘和内存。选方案时应比较整套环境的成本；“官方支持流式”不等于“最适合 Windows 桌面的轻量安装”。已有省资源的方案能满足使用时，可以继续使用。

可以安装多个模型，再在界面切换。**已登记不代表当前已启动**；正在录音、重转写或测试连接时不能切换。重启电脑后是否自动启动本地服务，由安装 Agent 配置，出现服务未启动时可以请它检查。

若需要排查，给 Agent 发送圈说设置里复制的安装提示词，以及具体错误文字即可。技术接入必须符合圈说的协议；随便填一个本地模型网址不能保证能用。

## 五、不想配置本地模型，可以用云端

云端方案使用阿里云百炼，需要联网和你自己的 API Key，费用由所选服务的实际计费规则决定。圈说开源免费，并不代表第三方云端识别免费。

1. 在阿里云百炼开通所需服务并创建 API Key。
2. 打开圈说 **设置 → 语音识别**，选择阿里云来源，填入 Key，选择合适的模型和麦克风。
3. 点 **测试连接**，通过后实际说一句试试。**云端测试会短暂打开麦克风并连接阿里云**。

想边说边出字，需要使用流式识别模型。部分模型是在录音结束后整段转写，不会实时出字。

本地连接测试与云端不同：本地测试发送半秒静音，不打开麦克风，主要检查服务协议是否可用。两种来源的地址和模型分别保存，失败时不会偷偷切到另一种来源。

API Key 使用 Windows 当前用户加密保存。不要把 Key 放进反馈截图、公开帖子或 GitHub Issue。

## 六、记录去哪了？怎么找回来？

在托盘双击打开历史，可以：

- 搜索原话，或点日历按日期查找。
- 打开一条记录继续改文字，复制给 AI，或只复制文字。
- 进入批量选择，使用 Ctrl / Shift 多选；Ctrl + A 全选，Ctrl + C 合并复制，Esc 退出选择。
- 在转写失败的记录上点 **重新转写**。前提是原录音仍在，并已修复识别配置。
- 删除到回收站，并通过提示条撤销误删。
- 在设置里切换星湖、海棠两套外观；希望安静一些时可启用安静模式。

默认文件夹是 **用户文档 → QuanShuo → 日期**。截图是 PNG，文字和来源是 Markdown，录音是 WAV。文件可以脱离圈说直接打开。

**成功转写后默认会删除 WAV**，可在设置中选择保留。识别失败时会保留已有文字和录音，便于重试。更改数据目录后需要重启，旧记录不会自动迁移，搬迁前先备份。

## 七、隐私与使用边界

- 截图和记录保存在本机；圈说没有账号体系和遥测。
- 云端语音识别会把音频发送给阿里云；本地模式把音频发送给本机识别服务。
- 你把内容发给其他 AI 后，后续处理取决于那个 AI 工具。复制前检查是否含有不想分享的截图、路径、窗口标题或文字。
- 程序使用可修改的全局快捷键，不安装全局鼠标或键盘钩子。
- 当前是预览版。不同麦克风、噪声、混合 DPI、多屏和全屏游戏的表现仍需更多实际验证；重要内容请检查识别结果。
- 代码采用 MIT 许可；第三方库、字体和语音模型有各自许可，详见仓库的第三方声明。

## 八、遇到这些情况，先这样处理

| 现象 | 先检查什么 |
| --- | --- |
| 程序开了，没有窗口 | 看右下角托盘和小箭头；双击圈说图标，或再次运行程序 |
| 快捷键没有反应 | 到设置换一组快捷键，排除与其他软件冲突 |
| 录到了声音，却没有文字 | 检查是否配置了识别来源；查看错误提示。整段转写模型需要等录音结束 |
| 本地服务连不上 | 让安装 Agent 检查服务是否启动、模型是否可用、应用是否接到了正确服务 |
| AI 说图片不存在 | 网页版通常看不到本机路径，需要另行上传图片；桌面 Agent 也要有读取该文件的能力 |
| 空格不能继续录音 | 可能正在编辑文字。点“继续”，或先把焦点移出文字框 |
| 思考了一会儿，录音暂停了 | 这是 1 分钟无语音自动暂停，点“继续”即可，不会自动丢掉之前的内容 |
| 麦克风打不开 | 在设置检查麦克风设备与 Windows 麦克风权限 |
| 安装器提示程序仍在运行 | 关闭窗口不等于退出；请在托盘右键选择“退出” |
| Windows 提示未知发布者 | 当前版本没有代码签名；核对官方仓库来源和发布页 SHA-256，不要关闭安全防护 |

仍无法解决时，到 [GitHub Issues](https://github.com/naname737373naname73-cmyk/QuanShuo/issues) 描述圈说版本、操作步骤、预期与实际结果，以及错误文字。截图前遮住 Key 和私人内容。
