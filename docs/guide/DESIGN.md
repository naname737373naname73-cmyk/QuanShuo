# 使用说明设计与素材来源

适用版本：QuanShuo 0.1.1。制作日期：2026-11-05。

这套说明包括六张竖版图、同版 PDF 和更完整的文字说明。文字按应用源码和现有说明核对；图中的电脑、托盘、窗口与人物是辅助理解的示意插画，不是应用实机截图。功能和按钮以实际版本及文字说明为准。

## 视觉设计

- 暖纸色背景、深蓝标题、海棠红重点，与圈说的星湖和海棠外观呼应。
- 每页只承担一个主题，依次介绍价值、安装、操作、本地识别、云端与记录、常见问题。
- 快捷键、模型名称、资源预算和关键按钮保留具体名称；资源预算强调可用余量。
- 不把本机图片路径描述为已上传图片，不把自动暂停描述为释放模型显存。

## 图片来源与维护

六张图片均使用 Codex 内置生图工具 `image_gen` 生成，并逐页人工式视觉检查；没有使用第三方图库照片或应用截图。完整生成提示词保存在 [design-prompts.json](design-prompts.json)，其中的颜色、字体风格和文本可以作为后续版本设计参考。

修改功能后，先更新 [文字说明](README.md)，再更新对应图片和版本标记，重新导出 PDF。图片中的图标属于示意图，不作为正式品牌图标使用。PDF 使用原图排版；需要搜索、复制、翻译或辅助阅读文字时，使用 Markdown 文字版。
