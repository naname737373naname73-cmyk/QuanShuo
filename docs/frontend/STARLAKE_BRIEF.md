# 星湖：圈说界面设计说明

这份文件是界面重构的唯一设计依据，覆盖此前“春日大树”的全部视觉要求。花、树、枝叶、花瓣都不再使用。

## 概念

一片高山镜湖。上方是星空与雪山，下方是倒映它们的水面。

- 一次圈说 = 湖面的一圈涟漪。“圈”是产品名，也是涟漪。
- 一条记录 = 天上亮起一颗星。今天的记录连成一头鲸的星座。
- 说话 = 声音在湖面激起涟漪。
- 复制给 AI = 一颗流星划过。

参考图只提供气质，图片本身不得进入应用：
1. 蓝调时刻的雪山星空：深蓝到紫再到桃色的天光、细密分层的星、一颗孤悬亮星、一道卫星轨迹。
2. 水面上的蓝发鲸尾少女：高调的浅水蓝、同心涟漪、四芒闪光、蓝宝石色与白色蕾丝的对比、细金线、大面积留白、一只小鲸鱼图案。人物不进入应用，只取鲸的意象。

## 气质

安静、辽阔、精致。大面积留白，细线条，克制的高光。像一台精密仪器放在月光下。不要赛博霓虹，不要紫粉渐变按钮，不要大圆角玩具感，不要 emoji。

| 蓝宝石 | `#111A45` | 面板主色 |
| 靛蓝 | `#1E2A63` | 悬停、抬升 |
| 钴蓝 | `#2F4BB8` | 浅色模式强调 |

| 警示 | `#FF9C93` | 错误 |

暖色是点睛，单个界面面积不超过 2%。

## 字体

- 标题与大数字：Noto Serif SC（前端内置子集）。原生层用系统已装的 `Noto Serif SC`，没有时退回 `Microsoft YaHei UI Light`。
- 界面文字：Segoe UI Variable / Microsoft YaHei UI。
- 时间、路径、尺寸、快捷键：Cascadia Mono，退回 Consolas。

## 形状

圆角：控件 8，卡片 14，大面板 20。边框 1 物理像素的发丝线。阴影极轻。图标 1.5 线宽。四芒星是唯一的装饰符号。

## 动效

确认和取消永远不等动画。操作反馈 150ms 内。氛围动效可以更长但不能阻塞。安静模式和系统“减少动画”下全部停止。

## 桥接新增

| 类型 | 方向 | 负载 | 说明 |
| --- | --- | --- | --- |
| `window.minimize` | 前端 → 原生 | `{}` | 最小化历史窗口 |
| `window.toggleMaximize` | 前端 → 原生 | `{}` | 最大化或还原 |
| `window.close` | 前端 → 原生 | `{}` | 已有，销毁窗口 |
| `window.state` | 原生 → 前端 | `{ "maximized": bool }` | 导航完成后和状态变化时发送 |

历史窗口使用自绘标题栏。前端用 CSS `app-region: drag` 声明拖动区，自绘最小化、最大化、关闭按钮。
