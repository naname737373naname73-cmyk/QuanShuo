# 本地识别提示词拆分 · 2026-11-03

用户反馈 Kimi K3.1 收到旧提示词后，已开始下载或安装环境、模型。旧文档开头直接要求“请实际执行”，只对部分系统变动或较大下载提出询问，未把首次收到提示词时的只读评估独立出来。

按用户最新要求，应用改成两个独立复制按钮：

1. **① 复制检测选型提示词**，来自 [local-asr-assessment-prompt.md](local-asr-assessment-prompt.md)。只读检测、查官方资料、提出方案并交付摘要；不包含安装或验收命令。用户选定方案后仍先整理摘要，等第二阶段或用户另行明确要求安装。
2. **② 复制安装接入提示词**，来自 [local-asr-agent-prompt.md](local-asr-agent-prompt.md)。完整保留协议、诊断、配置和日常启动要求，执行用户已经选定的具体方案。缺少前文时只索取缺失的摘要和选择；已提供的信息不重复询问。

这两个按钮只复制相应文本。第一阶段的选择不会自动触发应用安装，第二阶段也不会把 agent 自写的“用户已同意”当成授权。切换 agent 时，用户需同时提供方案摘要和自己的明确选择。已有明确预算范围内的自动安装授权可沿用，后续收窄或暂停指令优先。

源码文档、应用内嵌资源、便携 ZIP 和安装目录都包含两份独立文件。安装器升级及卸载只处理这两个指定文档；不清理用户添加的其他文档、模型或环境。
