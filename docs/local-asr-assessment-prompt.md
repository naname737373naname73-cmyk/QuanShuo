# 圈说本地语音 · 第一阶段：看看电脑适不适合

请检查我的电脑是否适合使用文末指定的语音模型。没有指定时，帮我推荐一个省资源、能边说边出字的模型。**这一步只读检测，不下载、安装、启动或加载模型，也不改设置。**

## 自己完成检测

- 查询处理器、显卡和驱动、当前可用显存、内存和磁盘空间，以及圈说的位置、已有模型与服务。通过本机信息和官方资料解决技术问题，不把能自行查到的内容反问我；不读取密钥、私人录音或其他无关文件。
- 按日常还要运行其他软件来留余量，不能只看显卡标称 6 / 8 / 16 / 24 GB，也不能把模型文件大小当成运行占用。无法确定的性能就说明安装后试用才能知道，不为了测速启动模型。
- 确认所选模型能在这台电脑上运行，并能通过本机服务连接圈说、支持边说边出字。处理器方案也可以。安装和连接细节由你判断，不要求我选择技术组件。
- 已装好的模型优先复用。没有指定模型时，从 Paraformer Streaming INT8、Qwen3-ASR 0.6B / 1.7B 中推荐一个；所选模型不适合时，只给一个更轻的备选。

## 用人话告诉我结果

假设我不懂 AI 和电脑配置。默认用 3–5 句短话、约 150 字内回答：

1. 先说“适合”“可以用，但可能影响其他软件”或“暂时不建议”，再用一句话说明原因。
2. 说明大概要下载多少、留多少空间，以及是否容易让电脑变卡；估算要说“大约”，不知道就直说。
3. 告诉我下一步：想安装时，把圈说的“② 帮我装好”提示词发到这段对话即可。不要再问是否允许检测。

必要时可以多写一句关键限制；不展示硬件清单、命令、协议、运行时、量化等术语，不输出长表格或要求我整理交接摘要。来源与技术依据留在工作记录中，我问时再展开。缺少真正影响判断、又无法自行取得的信息时，最多集中问一次，用具体好回答的问题。

检测完成就结束本阶段；收到第二阶段提示词或我明确要求开始安装后，再执行安装。
