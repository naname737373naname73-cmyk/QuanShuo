# 托盘样式与空格暂停 · 2026-11-04

> **2026-11-06 更新：** 下文记录的是 11 月 4 日的实现。`0.1.2` 已将空格改为录音期间的临时全局快捷键，首次显示及切到其他应用后均可暂停/继续；圈说文字框编辑时放行，结束或隐藏时释放，冲突时使用按钮。仍不使用全局键盘钩子。下载版本和最新操作说明见[使用指南](guide/README.md#暂停继续和自动暂停)。

托盘改为独立的原生菜单组件：圈选截图和说话、历史与设置、退出。按用户后续反馈，收简为中性灰白/深灰的纯文字菜单，去掉品牌抬头、花纹、图标和快捷键外框；深浅随现有皮肤切换。键盘提示单独右对齐，按实际长度留宽，不重复注册全局快捷键。原生菜单继续负责方向键、回车、Esc、失焦关闭和屏幕边缘避让；录音卡的更多复制菜单不变。

字体按缩放缓存，菜单销毁时解除主题事件并释放字体。菜单打开时重算尺寸，再按实际窗口 DPI 校正并限制在工作区内。修改快捷键也同步托盘悬浮提示。

录音卡和纯语音窗口打开时，焦点在暂停按钮。普通空格暂停/继续，长按只触发一次；截图阶段遗留的空格抬键不会误停新录音。点击文字或 Tab 进入编辑后，空格和输入法选词正常工作；点击窗口空白处可回到录音控制。只处理当前录音窗口内的按键，不增加全局键盘钩子。收尾和结束后不再暂停。

验证入口：

```powershell
dotnet run --project tests/QuanShuo.Recording.Tests -c Release
QuanShuo.exe --smoke-skins --smoke-output skins.txt --smoke-shots shots
dotnet run --project tests/QuanShuo.Core.Tests -- verify-delivery
```

皮肤预览覆盖星湖、海棠、100%/150%/200% 的排版和较长快捷键；简约版图片在 `artifacts/tray-minimal-20261104/shots`，此前花笺版图片保留在 `artifacts/tray-refresh-20261104/shots`。录音键盘检查使用假回调和合成记录，不启动麦克风或 ASR。不同 DPI 的实体双屏切换与真实人声识别不在本轮验证范围内。

这次阅读了用户提供的 Qwen 部署复盘作为背景；没有执行其中安装、模型变更或提示词修改的建议。
